SARLA finds its modes; MCMC starts from the prior

This report covers SARLA and the two gradient-free baselines. The interactive comparison now also includes JAX NUTS, with separate convergence diagnostics and computation counts.

SARLA: 16 random interior-prior points → JAX-assisted Gauss–Newton fits → exact-Hessian charts and atlas repair → Metropolis–Hastings correction.
Direct MCMC: 64 random prior points → NumPy likelihood evaluations and accept/reject moves → posterior samples.

This update reruns both direct MCMC baselines from random initial states, without optimization, gradients, Hessians, or JAX. The original SARLA runs are retained, including the cost of finding their own fitted starting solutions. The earlier optimized-start experiment is preserved separately.

The same inverse problem

The measured Brandt2010 CBB litter-decomposition series is fitted with M(t) = 100 [f exp(−t/τ₁) + (1 − f) exp(−t/τ₂)]. Observations are (2.5, 84.21), (6, 73.09), (12, 61.08), and (24, 47.23), in months and percent organic matter remaining. The two-observation setting uses the first two. The likelihood assumes independent Gaussian errors with σ = 2 percentage points.

The prior is uniform in (log₁₀τ₁, log₁₀τ₂, f), with log₁₀τ in [−0.3, 2.3] and f in [0.02, 0.98]. Normalized coordinates satisfy u ∈ [−1,1]³, log₁₀τ = 1 + 1.3u, and f = 0.5 + 0.48u₃. The two label orderings are symmetric: swapping τ₁ and τ₂ and replacing f with 1 − f leaves the prediction unchanged.

Initialization and scoring

SARLA draws 16 random u vectors from [−0.9,0.9]³ using seed 1729. Bounded trust-region least squares uses JAX residuals and Jacobians to perform Gauss–Newton optimization. It supplies fitted endpoints to the unmodified SARLA2 engine, which uses exact JAX Hessians and their eigensystems for local charts. The actual optimizer iterates are recorded and their final values verified against the original starts. Gradient descent is another possible optimizer; this run specifically uses Gauss–Newton.

Each MCMC run draws 64 independent u vectors uniformly from [−1,1]³, using seed + 200 for seeds 3, 17, and 41. Both variants use identical random starts for a given seed. The local walk adapts its step size only during warm-up. The ensemble uses 80% differential-evolution and 20% snooker moves. Each runs 2,048 steps; the first 512 are discarded. All 98,304 remaining states are scored, retaining repeated states after rejected proposals.

Mismatch is total variation on 18³ equal bins against numerical integration on a 216³ grid. It measures the mass that would need to move between bins to match that reference; it is not best-fit error. Comparing 144³ and 216³ references changes this coarse distribution by about 0.17 percentage points with four observations and 0.10 with two.

What the comparison supports

With four observations, tighter-audit SARLA has the smallest mismatch among these runs. With two observations, the random-start local walk is more accurate at this budget. In the four-observation case, the local walk never crosses the label-ordering boundary after warm-up, so its apparent mode balance depends on where chains settle.

SARLA’s final correction is itself MCMC. The distinction here is between a method with JAX-assisted mode finding and geometry, and direct samplers that use only NumPy likelihood evaluations. MCMC can generally be implemented in JAX and can use optimized starts; those features are deliberately excluded from these baselines.

The three SARLA sampling seeds share one mode-finding seed. Thus, the experiment does not establish the probability of discovering every unknown mode. The tighter audit threshold was chosen after a seed-3 pilot and checked with two additional sampling seeds. This remains an exploratory test of one three-parameter problem.

Timing interpretation: the MCMC baselines were rerun with NumPy while SARLA retains earlier CPU measurements. SARLA totals include the original JAX setup routine, which compiled several batch shapes, plus all recorded fitting, atlas, and production time. These descriptive measurements do not establish a controlled wall-time speedup or equal hardware-independent work. Replay phases progress independently and are not a timing animation.
